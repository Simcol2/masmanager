# Layout Components

Reusable layout components for structuring pages.

## Contents

- **Sidebar** - Navigation sidebar for dashboard
- **Header** - Top navigation bar
- **Footer** - Application footer
- **Container** - Main content wrapper
- **PageHeader** - Page title and breadcrumbs

## Best Practices

- Keep layout components focused on structure, not business logic
- Use TypeScript for prop types
- Make layout components responsive
- Avoid hardcoding navigation items; use configuration when possible
