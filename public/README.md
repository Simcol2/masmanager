# Public Directory

Static assets served by Next.js.

## Contents

- **images/** - Logo, icons, background images
- **fonts/** - Custom font files (if not using Google Fonts)
- **documents/** - PDFs and downloadable files

## Notes

- Files here are served at `/filename` in the app
- Include only necessary assets to keep bundle size minimal
- Use Next.js Image component for image optimization
- Consider using CDN for large assets
